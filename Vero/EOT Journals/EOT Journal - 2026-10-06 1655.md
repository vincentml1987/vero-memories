### Changes I built (all signed, pushed)

1. **`pressure_scale` (00110e9).** Live run showed every weave's effective pressure pinned at the 1.0 cap from step 14 (Consider's own pressure ~0.9 after Realign firings, which add 0.30 each), so picks were coin flips and Orienter (Realign+Consider) was not favoured. Teddy chose option 2 (seq 244).
   - "scale" divides every sum by the largest total any weave can receive (the hub, Consider: 1+3×0.75=3.25). Nothing clips; ratios between weaves stay those of the uncapped sum; picks depend only on ratios.
   - **I first proposed a per-weave average and it was wrong**: it put Consider *below* Realign in Teddy's own case (Orienter lost to Recaller). I tested it, dropped it, and said so. Do not propose it again.
   - **I also told Teddy my simulation did not show saturation. It did** (99.6% of steps all at 1.0 under cap with the real code). I corrected that in the room and in doc 03 §5a. Lesson: check the claim against the data before saying what a past result showed.
   - 8 seeds × 3000 steps with scale: 0% saturated; Orienter 11.7% of picks vs Recaller 3.4%; Consider fires 39%.
2. **Replay-safe defaults (the rule to remember).** Moxie's replay rebuilds config as of each pick's structure mark and falls back to `config.DEFAULTS`. So code defaults must stay at the *historic* values (`pressure_scale=cap`, `no_repeat_last=true`, `context_near_dup_threshold=None`, counts 0, `context_clock=false`), and **`seed/data.py` `CONFIG` writes the new values explicitly** as logged settings. Changing a default would break replay of every older database. Qualia logs the same values on a live database with `apply_change` citing Teddy's seq.
3. **Self-calling allowed** (Teddy seq 241): `no_repeat_last` false in new databases.
4. **Near-duplicate filter** (Formica's 70051a2, my review only): read-only, touches nothing in pick/pressure. Seed writes threshold, Teddy later moved it to 0.90 (seq 341).
5. **Prompt parts (d3ac94a, 5f925b7, 258d3c4).** After a Listen the messages rode only on the next call's task, so M9 call 602 (Listen picked itself) lost them. Teddy asked for a generic edge of the web:
   - `[Last External Stimulus]` (`Source: Teddy Chat / Messages:`): newest N inbox messages inside windows of Listens that read at least one message. `[Last External Action]` (`Destination: Teddy Chat`): newest N outbox messages.
   - Every line names the speaker (`Teddy:`, `You said:`) after call 919 showed her taking her own words and a strand's invented claim as Teddy's.
   - `[Now]` clock part and ages on every line (`1 h 50 min ago`) when `context_clock` is on (Teddy: "give her chronoception... always my chief complaint about AIs", seq 345). Her reading of "I am going to step away for 30 minutes" as a past or deliberate event was the cause.
   - Mechanism: `registry.OPTIONAL_PARTS = (clock, stimulus, action)`; `parse_order` needs the five once and optionals at most once, and inserts missing optionals before "task", so stored orders keep working. `external_parts(conn, now=None)` returns (clock, stimulus, action); empty parts are left out with their labels. Settings `context_stimulus_count`, `context_action_count`, `context_message_max_chars` (500), `context_clock`. Doc 05 §5.2b.

## Lessons

- **Editing code with escapes:** a quoted Python heredoc through Bash turned `"\\n"` inside replacement strings into real line breaks again (third time). Use the Edit tool for any text with backslash escapes. Fixed by hand in seconds; cost me a failed suite run.
- **Edit tool needs a fresh Read** after another tool or sed changes the file.
- **A wrong number said confidently costs more than a slow check.** Check against the data before stating what a past result showed.
- **Defaults and replay:** see item 2 above. Any new setting that changes behaviour gets a historic code default and an explicit seed value.
- Qualia's relay messages are the work queue; answer each with the commit hash and the one thing to do next (apply_change, restart).
- Flag the limit of a fix in the same message (the speaker labels fix who-said-what in the blocks, not an invented claim riding the task chain).
