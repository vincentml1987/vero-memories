## Lessons

- **Never chain a commit after a long test run** (`pytest | tail && git commit`): when I killed a hung pytest, the chain went on and committed untested. Run tests, read the result, then commit.
- **The full suite is slow while the 27B runs** (17 minutes once); run the touched suites first, the whole one in the background.
- **Heredocs through this shell turn `\\n` into real newlines**: write Python patch scripts with the Write tool or use Edit (hit it twice again this session).
- Say plainly what I did not verify (the `<bos>` question, the 27B think block) and who has to test it; I will not load a 17 GB model here.
